Thrusters

Toggle on, then click the hull where each engine nozzle is. Markers are saved into the GLB as empty nodes named thruster1, thruster2, ... (renumbered if you delete one). Esc exits placement. You can also type exact X/Y/Z coordinates in the list below to fine-tune each marker.

Guns

Toggle on, then click the hull at each gun muzzle. Markers save into the GLB as empty nodes named gun1, gun2, ... so the game knows where to fire from. Esc exits placement. You can also type exact X/Y/Z coordinates in the list below to fine-tune each marker.

Cockpit

Toggle on, then click the hull where the cockpit sits. Markers save into the GLB as empty nodes named cockpit1, cockpit2, ... so the game knows where the pilot/canopy is. Esc exits placement. You can also type exact X/Y/Z coordinates in the list below to fine-tune each marker.

Glass Paint

Select the hull surface, toggle on, then left-drag to paint the canopy glass green. Right-drag orbits, wheel zooms, Shift erases, [ ] change the brush. Mirror paints both sides at once. Export writes <ship>_glass.json; put it in tools/blender/marks/ (or use Save to pipeline while python tools/glb_editor_server.py runs) and the cockpit pipeline uses exactly these faces as the window.
