eml blocks

minecraft, but every block is carved by its own eml

solid = fill·d − ( g·(e^(k·n)−1) − L·ln(d) ) − iso
d = depth into the block (0 at an exposed face, 1 at skin-depth R and beyond). n = the material's noise. e^(k·n) chews texture everywhere; −ln(d) bites at the skin. Same block grid, different carve per type.
what counts as "skin"
fused: blocks merge, only faces open to air erode. per type: seams between materials erode too. isolated: every block is its own carved boulder.
eml DNA ·
differentiation · one genome, many roles
Every cell reads morphogens from the whole it belongs to: how tall its stack is and where it sits in it, how long its row runs, whether air is beneath it and whether that gap is held up at both ends. The role it finds switches genes on. Genes only add "air" or reshape the distance to air, so the eml carve still does the texture.
