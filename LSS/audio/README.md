# LSS announcer audio

Pre-baked MP3s of every line the ship-AI announcer can say. The Meta Quest
browser plays these directly off GitHub Pages, no backend required.

## Files

- `lines.json` - source of truth: every line, voice config, and ship-name
  variants for `welcomeAboard`.
- `bake.py` - Python script that calls ElevenLabs and writes the MP3s.
  Uses only the standard library; no pip install needed.
- `manifest.json` - generated by `bake.py`; the in-game client uses it to
  look up which MP3 to play for a given line text.
- `<sha256-16>.mp3` - one file per unique line. Content-addressed, so the
  same text always lands at the same filename. Safe to commit; safe to
  delete and re-bake.

## Bake the audio (one time, and whenever lines change)

```bash
cd LSS/audio
ELEVENLABS_API_KEY=sk_your_key_here python3 bake.py
```

On Windows PowerShell:

```powershell
cd LSS\audio
$env:ELEVENLABS_API_KEY = "sk_your_key_here"
python bake.py
```

Options:

- `--force` - re-bake every line even if the MP3 exists.
- `--dry` - print the plan without calling ElevenLabs or writing files.

The script is **idempotent**: it skips files that already exist on disk
unless `--force` is set, so re-running after a small change only re-bakes
the new entries.

## When you add or change a line

1. Edit `lines.json` (add an entry, or change the text).
2. Run `python3 bake.py`. Only the new / changed lines get re-baked.
3. `git add` the new `.mp3` files and `manifest.json`, commit, push.
4. GitHub Pages serves the new files automatically.

If you remove a line, you can also remove its `.mp3` by hand; the manifest
will no longer reference it after the next bake.

## Pick a different voice

Either edit `voice.id` in `lines.json` and re-bake with `--force`, or set
the env var:

```bash
ELEVENLABS_VOICE_ID=<some-id> python3 bake.py --force
```

Browse your voice library at <https://elevenlabs.io/app/voice-library> and
copy the ID from the voice's page.

## Total cost

The full catalog is about 1,200 characters, well inside ElevenLabs' free
10k-chars-per-month tier. Re-baking the whole thing from scratch uses
~12% of your monthly quota.
