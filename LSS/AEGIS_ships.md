# Aegis Ships



## What "Aegis" means

Aegis Ranks are specialised Ship upgrades specific to LSS's hub mode. They augment a Ship to be **much more powerful than its baseline multiplayer version**. An "Aegis Ship" is simply a Ship that has earned some of these ranks.

Each rank is **per-Ship**: XP is locked to whichever Ship you picked on wave 1, so you level Ion, Scorch, Tone, etc. independently. There is no single account-wide Aegis level.

## How you earn ranks (Aegis Merits)

You gain Aegis XP every time you kill an enemy ship.

## When upgrades unlock

Upgrades are granted at **Aegis ranks 2, 5, 8, 11, 14, 17, and 20** — seven upgrades total per Ship. Two of the seven are **universal** (identical for every Ship); the other five are **Ship-specific**.

| Rank   | Upgrade type                                             |
| ------ | -------------------------------------------------------- |
| 2      | Ship-specific                                            |
| **5**  | **Chassis Upgrade (universal): +2,500 max health**       |
| 8      | Ship-specific                                            |
| 11     | Ship-specific                                            |
| **14** | **Shield Upgrade (universal): +2,500 max shield**        |
| 17     | Ship-specific                                            |
| 20     | Ship-specific (often the "ultimate" / signature upgrade) |

Upgrades are **always active** during hub (you don't slot them like Pilot kits), and they stack and synergize with each other and with the Ship's normal kits.

## ## Universal upgrades (every Ship)

- **Chassis Upgrade** (rank 5): "Your Ship's health is increased by 2,500."
- **Shield Upgrade** (rank 14): "Your Ship's max Shield is increased by 2,500."

## Quick reference: the universal pattern

Across all seven Ships the design is consistent:

- **Rank 2** boosts the primary weapon or signature trap.
- **Rank 5** is +2,500 HP (universal survivability).
- **Rank 8 / 11** deepen the Ship's identity (extra charges, ammo, weak-point damage).
- **Rank 14** is +2,500 shield (universal survivability).
- **Rank 17** is a second power spike on the same identity.
- **Rank 20** is the signature "ultimate" upgrade (e.g. Blaster's all-kits *Dreadnaught*, Slayer's *Blademaster*, Syphon's *Apex Ship*).
