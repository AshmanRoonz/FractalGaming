# Aegis Titans (Titanfall 2 Frontier Defense)

> Reference doc. "Aegis Titans" are not part of Last Ship Sailing; this is the vanilla **Titanfall 2** system, sourced from the Titanfall Wiki. Captured here because LSS borrows TF2's titan/loadout identities, and the Aegis upgrade tree is a useful template if you ever want a co-op or progression mode in LSS.

## What "Aegis" means

Aegis Ranks are specialised Titan upgrades specific to Titanfall 2's co-op horde mode, **Frontier Defense** (also used by the featured PvP modes Aegis LTS and Aegis Titan Brawl). They augment a Titan to be **much more powerful than its baseline multiplayer version**. An "Aegis Titan" is simply a Titan that has earned some of these ranks.

Each rank is **per-Titan**: XP is locked to whichever Titan you picked on wave 1, so you level Ion, Scorch, Tone, etc. independently. There is no single account-wide Aegis level.

## How you earn ranks (Aegis Merits)

You gain Aegis XP every time you finish a Frontier Defense match, win or lose, similar to multiplayer XP. XP is granted as **Merits**, earned from:

- **Mission Completion** — Easy/Normal = 1 Merit, Hard = 2, Master = 3.
- **Waves Completed** — 1 Merit per wave (max 5).
- **Retries Remaining** — 1 Merit per unused retry (max 2).
- **Unique Titans** — 1 Merit if the squad has no duplicate Titan picks.
- **Wave Milestone** — 1 Merit per wave where the team killed at least 50% of enemies (max 5; not available on Easy).
- **Aegis Bonus** (limited-time, 2017) — 1 Merit per squadmate using an Elite Warpaint (max 4).

Merits are only awarded for rounds you actually played; joining a match late earns nothing for earlier rounds.

## When upgrades unlock

Upgrades are granted at **Aegis ranks 2, 5, 8, 11, 14, 17, and 20** — seven upgrades total per Titan. Two of the seven are **universal** (identical for every Titan); the other five are **Titan-specific**.

| Rank | Upgrade type |
| --- | --- |
| 2 | Titan-specific |
| **5** | **Chassis Upgrade (universal): +2,500 max health** |
| 8 | Titan-specific |
| 11 | Titan-specific |
| **14** | **Shield Upgrade (universal): +2,500 max shield** |
| 17 | Titan-specific |
| 20 | Titan-specific (often the "ultimate" / signature upgrade) |

Upgrades are **always active** during Frontier Defense (you don't slot them like Pilot kits), and they stack and synergize with each other and with the Titan's normal kits.

## Difficulty gating

Higher difficulties unlock once you have a Titan at the required rank, and a difficulty can only be played with a Titan of appropriate rank:

- **Hard** — requires a rank 5 Titan.
- **Master** — requires a rank 11 Titan.
- **Insane** — requires a rank 14 Titan.

## Universal upgrades (every Titan)

- **Chassis Upgrade** (rank 5): "Your Titan's health is increased by 2,500."
- **Shield Upgrade** (rank 14): "Your Titan's max Shield is increased by 2,500."

## Quick reference: the universal pattern

Across all seven Titans the design is consistent:

- **Rank 2** boosts the primary weapon or signature trap.
- **Rank 5** is +2,500 HP (universal survivability).
- **Rank 8 / 11** deepen the Titan's identity (extra charges, ammo, weak-point damage).
- **Rank 14** is +2,500 shield (universal survivability).
- **Rank 17** is a second power spike on the same identity.
- **Rank 20** is the signature "ultimate" upgrade (e.g. Legion's all-kits *Dreadnaught*, Ronin's *Blademaster*, Monarch's *Apex Titan*).

## Relevance to Last Ship Sailing

LSS already maps the same seven titans to chassis classes and has a core-meter system. If you ever add a co-op/horde or progression mode, the Aegis tree is a clean template: per-loadout XP, fixed unlock ranks, two universal survivability bumps (which in LSS would map naturally to the chassis health/shield pools in `CLAUDE.md`), and a signature capstone per loadout. Note this is a **PvE progression layer**; LSS's current design is round-based PvP elimination with no permanent upgrades, so adopting it would be a new mode, not a change to existing balance.
