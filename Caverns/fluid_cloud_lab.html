fluid CLOUD lab

lit volumetric clouds · real fluid (after saharan · Chill)

A true 3D fluid: a velocity+smoke grid that's advected, made incompressible (pressure solve), and given curl (vorticity confinement). Drag in the view to grab the ball and seed cloud; the gas is buoyant so it rises and billows, sun-lit so it self-shadows like real cumulus. Carried by the flow, so it tears and swirls, not pushed paint.
vorticity = how much it curls/billows. power = jet strength. ventilation = a room draft that slowly clears the smoke.
